# Autóműhely – Python a gyakorlatban

Nyisd meg az index.html fájlt. Internet nélkül is működik; nincs telepítendő webes csomag.

## Használat Thonnyval

A weboldal a munkafüzet, a kódot Thonnyban futtatjuk. Mentsd a .py és a hozzá tartozó .txt fájlt ugyanabba a mappába. A `programok` mappában minden minta teljes és önállóan futtatható, az adatfájlok is mellette vannak. F5: futtatás. A `garazs_teljes.py` a teljes autós feladat mintamegoldása. A `sajat_garazs.py` kitölthető feladatváz.

19 fokozatos tanulási lépés, 12 autó, 10 hegycsúcs, 28 kérdéses újrakezdhető tudáspróba. A részletes 240 perces javaslat és az ellenőrző eredmények a `tanari.html` oldalon találhatók.

## GitHub Pages

Az összes kibontott fájlt és az `adatok`, `programok` mappát töltsd a webhely közzétett könyvtárába. Az index.html legyen annak gyökerében. A hivatkozások relatívak, ezért projekt-almappában is működnek. Nincs külső betűkészlet, függőség vagy adatküldés. A teszt gyakorlásra készült, megoldásai a kliensoldali forrásból megismerhetők.

## Adatok

Az autók fiktív tanulóadatok; a gyorsulás az 1–100 km/h időt jelenti másodpercben. A hegyadatok KSH-táblázatból rögzített gyakorlóadatok; forrás és megjegyzések a tanári útmutatóban. A TXT fájlok UTF-8 kódolásúak, pontosvesszős elválasztásúak, fejléc nélkül.
